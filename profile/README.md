## What it is

OurDream is a companion app, not a general chatbot. The loop is: pick or create a character, talk, then add a picture, a short clip or a call without leaving that character. Appearance, personality and scenario are part of setup. The public library is large enough that you can skip building and start from someone else's character.

It runs in the browser on desktop and phone. You do not install a separate app to try the core flow.

## What you can do

- **Chat.** Conversations stay tied to a character, which is the point if you want continuity rather than a blank session each visit.
- **Create a character.** Appearance, personality and the kind of scene you want. You can also start from the community library.
- **Images.** Stills of that character, including realistic and anime-style output. Generation spends DreamCoins.
- **Video.** Short clips of the same character. Clips cost more coins than stills.
- **Voice.** Voice messages and live calls, also metered in coins.
- **Group scenes.** More than one character in a thread, for people who want a cast rather than a single companion.

Coin costs and plan limits move. Treat any number you see on a review as unchecked until you see it on ourdream.ai.
